本地測試與協作指南（給想動手測試的高手們）
如果你想將專案下載到自己電腦上進行測試、跑跑看或嘗試修改，請務必遵循以下步驟與安全規範：

1. 複製專案：使用 `git clone` 將專案下載到本地。
2. 安裝依賴套件：於終端機執行 `pip install -r requirements.txt`。
3. 設定環境變數（絕對安全注意）：
    請在本地專案根目錄自行建立一個 `.env` 檔案。
    在裡面填入你自己的測試用 Discord Bot Token 與 Gemini API Key（建議不要使用正式機器的金鑰，也絕對不能把金鑰硬編碼寫在程式碼裡）。
    專案內已設定好標準的 `.gitignore`，會自動把 `.env` 排除在外，防止不小心推送到公開網路上。
4. 本地運行：執行 `python main.py` 即可在你的測試伺服器上啟動並檢查效果！
